A premium, White Glowing Smooth aesthetic for Spotify via Spicetify. Designed with a focus on minimalism, soft depth, and fluid transitions.

##  Features

- Soft White Glow: Replaces harsh lines with subtle shadows and depth.
- Glassmorphism: A blurred, semi-transparent top bar for a modern feel.
- Buttery Smooth: Custom `cubic-bezier` transitions for all UI interactions.
- Dynamic Greeting: JavaScript-powered time-aware greetings (Morning/Afternoon/Evening).
- Refined Cards: Elevated card states with hover lifting effects.
